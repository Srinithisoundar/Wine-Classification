# Wine-Classification
Wine Classification - Machine Learning : Codsoft

Wine Classification – CodSoft Machine Learning Internship
Project Description

Wine Classification is a machine learning project that aims to classify wine samples into different categories based on their chemical properties. The project uses the Wine Recognition dataset from Scikit-learn and applies a Random Forest Classifier to predict the wine class.

Objectives
Analyze and preprocess the wine dataset.
Build a machine learning classification model.
Train and test the model using training and testing datasets.
Evaluate model performance using accuracy, precision, recall, and F1-score.
Visualize the results using a confusion matrix.
Technologies Used
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
Algorithm Used

Random Forest Classifier

Dataset

The Wine Recognition dataset contains 178 samples, 13 chemical features, and 3 wine classes.

Methodology
Load the wine dataset.
Explore and analyze the data.
Split the dataset into training and testing sets.
Train the Random Forest classification model.
Predict the wine classes.
Evaluate the model using classification metrics.
Visualize the results using a confusion matrix.
Conclusion

This project demonstrates the application of supervised machine learning for wine classification. It provides practical experience in data preprocessing, model training, prediction, and performance evaluation.
